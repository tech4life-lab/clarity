# Clarity

Clarity of thoughts and mind — marketing site and waitlist (React, TypeScript, Vite).

## Develop

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and fill in Supabase / PostHog keys for local testing.

## Build

```bash
npm run build
```

Static output is in `dist/` (suitable for Vercel or any static host).
